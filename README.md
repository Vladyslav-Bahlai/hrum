# Хрум — дневник питания с ИИ

React Native (Expo SDK 58) · Android и iOS · данные хранятся только на телефоне.

## Что умеет
- **Меню доставки**: фото или текст меню → ИИ раскладывает блюда по номерам и разделам (завтрак, второй завтрак, обед, салат, ужин, второй ужин) с КБЖУ. Меню — отдельная сущность: его можно привязать к нескольким дням, убрать из дня или удалить совсем. Несколько фото — несколько отдельных меню; названия по умолчанию — «Понедельник, 2 ноября».
- **Отметка из меню одним тапом**: «+» у блюда, «Съел всё меню», карточка «Выбрать с меню» на главном экране (если меню на день нет — сначала предложит добавить). Можно написать «съел №3» или «половину обеда» — ИИ получает меню выбранного дня.
- **Привезли другое**: блюдо в меню заменяется из «Моих блюд» или вручную.
- **Мои блюда**: пресеты (вручную или через ИИ по тексту/фото) + всё, что было в меню и дневнике, с поиском.
- **Порция или граммы**: везде переключатель «Порция ⇄ Граммы» (¼…2 или граммы ±10 и быстрые 50…300).
- **Ввод одной строкой**: «овсянка 250 г с бананом и кофе с молоком» → ИИ возвращает блюда с калориями, БЖУ, клетчаткой, сахаром и весом.
- **Фото**: камера или галерея (до 4 снимков) — тарелка, упаковка с этикеткой, меню на день или ресторанное меню. Из меню отмечаете, что съели.
- **Порции**: крупные кнопки ¼ · ⅓ · ½ · 1 · 1½ · 2, а также любой множитель вручную.
- **Жесты**: свайп по экрану — предыдущий/следующий день. Удержание записи «замораживает» две кнопки — «Повторить» и «Удалить»; любое другое касание или прокрутка их убирает. Пока видно «Отменить», интерфейс не реагирует, а тап мимо только прячет окошко.
- **Прошлые меню**: на вкладке «Меню» — последние три, «Показать все», раскрытие состава по тапу, «Съедено полностью» (убирает из списка переноса), «Убрать из дня», «Удалить меню». Вместо поля ввода внизу — панель инструментов меню.
- **Категории дневника**: по умолчанию завтрак, обед, ужин; свои категории и часы — в настройках.
- **Ручное добавление** блюда кнопкой с карандашом в поле ввода; модель ИИ меняется прямо там (список запоминается при проверке ключа).
- **Быстрые блюда**: избранное и частые блюда появляются над полем ввода — один тап, и блюдо добавлено.
- Дневная норма (свой ввод или расчёт по Миффлину — Сан-Жеору), вода, вес.
- **Неизвестное ≠ ноль**: калории и БЖУ можно не указывать — пустое поле не считается нулём. В итогах дня и статистике рядом с числом стоит «+?», на графике — пунктирный «?», в полосе БЖУ — серый сегмент, вверху статистики — «Данные полные на N%».
- **Вкладка «Дополнить»**: блюда без калорий/БЖУ за сегодня, неделю или всё время одним списком. Заполнили один раз — значение встаёт во все записи, меню и «Мои блюда». Подсказки из уже известных данных и кнопка «Заполнить через ИИ».
- **Конструктор меню**: меню можно собрать вручную — разделы (завтрак, второй завтрак, обед, салат, ужин, второй ужин), нумерация, порядок, блюда из «Моих блюд».
- **Звуки природы** вместо вибрации; для каждого события — свой звук, «без звука» или свой файл (настройки → Звуки). Заставка с логотипом при запуске.
- Плавные свайпы: день движется за пальцем, строка записи мягко схлопывается при удалении.
- Календарь с отметками дней (в норме / перебор / есть пробелы).
- Статистика за неделю, месяц и 3 месяца: среднее, дни в норме, баланс к норме, серия, график по дням, доли БЖУ, распределение по приёмам пищи, дни недели, вес, частые и самые калорийные блюда, время последнего приёма пищи.
- Экспорт и импорт резервной копии (JSON).

## ИИ
Настройки → «Искусственный интеллект»:
- **Gemini** — бесплатный ключ: https://aistudio.google.com/app/apikey
- **Claude** — ключ: https://console.anthropic.com/settings/keys

Кнопка «Проверить и сохранить» проверяет ключ и подгружает список моделей. Ключ хранится в защищённом хранилище телефона (Keystore/Keychain) и отправляется только напрямую в Google или Anthropic.

## Где лежат данные
`<папка приложения>/Hrum/data.json` — дневник, `Hrum/photos/` — фото, `Hrum/backups/` — экспорт.

## Запуск и сборка
```bash
npm install
npx expo start                 # разработка
npx expo prebuild -p android   # сгенерировать android/
cd android && ./gradlew assembleRelease   # APK: android/app/build/outputs/apk/release/
```
iOS: `npx eas-cli build -p ios` (нужен аккаунт Apple Developer) или `npx expo run:ios` на Mac.

## Структура
- `App.tsx` — корень, онбординг, экраны статистики и настроек
- `src/screens/DayScreen.tsx` — главный экран дня (свайпы, вода, записи)
- `src/screens/Composer.tsx` — плавающая панель ввода (текст, камера, галерея)
- `src/screens/ReviewSheet.tsx` — проверка результата ИИ, порции, ручной ввод
- `src/screens/StatsScreen.tsx`, `SettingsScreen.tsx`, `CalendarSheet.tsx`
- `src/ai.ts` — запросы к Claude и Gemini со строгой JSON-схемой
- `src/storage.ts` — файловое хранилище и ключи
